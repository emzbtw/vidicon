# 03: Docs, screenshots and the milestone review

Status: open. Blocked by: 02.

## Goal

A reader of the README or the site knows the built-in themes, how to
pick one, and how to write their own.

## Context

`docs/milestones/built-in-themes.md`. The README's Themes section and
`site/` (its Themes page is generated from the README). `tools/demo/`
for screenshots.

## Scope

- README Themes: the `theme` values, the eight built-ins with a credit
  and link per project, and user themes (the directory, the format with
  one example, missing tokens from the default, shadowing a built-in by
  copying its file from `assets/themes/`, editing it live).
- `docs/screenshots/themes.png` replaced or joined by a built-ins
  screenshot (the main screen under several palettes), against the
  demo provider.
- Milestone review: `code-review` since the commit that planned it.

## Acceptance

- [ ] README and site updated; site builds.
- [ ] Screenshots taken against the demo provider.
- [ ] Milestone review findings fixed.

## Out of scope

Release notes (the release itself, `docs/releasing.md`).
