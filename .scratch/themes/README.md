# Themes tickets

The milestone in `docs/milestones/themes.md`. One file per ticket in
`issues/`. Work any ticket whose blockers are closed; set `Status: done`
in the file when its acceptance boxes are all ticked.

Each ticket ends with a `code-review` of its diff (since the commit the
ticket started from), standards and the ticket as its spec; findings are
fixed in the same ticket before `Status: done`. Ticket 03 reviews the
whole milestone since the commit that planned it.

| # | Ticket | Blocked by |
|---|---|---|
| 01 | One palette for every colour | none |
| 02 | Theme file and the `theme` setting | 01 |
| 03 | Noctalia template, docs and screenshots | 02 |
| 04 | Ship the Noctalia template in the packages | 03 |
